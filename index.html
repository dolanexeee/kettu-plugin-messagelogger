🗑️ Message Logger

Kettu plugin for iOS — keeps deleted and edited Discord messages visible.

Install

In Kettu: Settings → Plugins → Install a plugin, paste this URL:

https://dolanexeee.github.io/kettu-plugin-messagelogger/

What it does

  • Deleted messages stay visible in place in the chat (the delete dispatch is blocked), with a toast confirming the catch.
  • Edited messages keep their history — up to 20 previous versions each.
  • Open the plugin's settings page to browse the full log (deleted + edited), with Refresh and Clear log. Up to 500 messages, persisted across restarts.

Honest limits

  • Only messages seen while the logger is running can be kept — nothing deleted before install/enable, or while the app was closed.
  • No red "deleted" badge on the message itself (the RN message renderer could not be verified for Discord 353.0). The message staying put + the toast + this log is the marking.
  • Kept messages disappear again if the channel is re-fetched from the server.
  • Not yet tested on a real iPhone — syntax- and behaviour-tested with a mock dispatcher only.
